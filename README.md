# Smart Tracking Jobs

ระบบจ่ายงานและเช็คอินรถตู้ สำหรับ **เจ้าของ / แอดมิน** และ **คนขับ** ใช้ได้ทั้งมือถือและคอมพิวเตอร์
ข้อมูลเก็บใน **Google Sheet** ของแต่ละบริษัท หน้าแอปเปิดผ่าน **GitHub Pages** — ไม่มีค่าเซิร์ฟเวอร์

**เปิดแอป:** https://finalflukle-cpu.github.io/smart-tracking-jobs/
**ลองระบบตัวอย่าง (ไม่ต้องตั้งค่า):** https://finalflukle-cpu.github.io/smart-tracking-jobs/?demo=1
**คู่มือติดตั้ง:** [SETUP.md](SETUP.md)

## ทำอะไรได้บ้าง

| ฝั่งเจ้าของ / แอดมิน | ฝั่งคนขับ |
| --- | --- |
| เข้าระบบด้วย PIN แอดมิน (เริ่มต้น `000000` เปลี่ยนเองได้) | เลือกชื่อ + ใส่ PIN 6 หลัก |
| ลงทะเบียนรถ (ทะเบียน รุ่น ที่นั่ง รูปรถ) และคนขับ (รูปหน้า เบอร์โทร PIN) | เห็นเฉพาะงานของตัวเอง พร้อมรูปรถที่ต้องใช้ |
| สร้าง Job: วันที่ เวลา คนขับ ทะเบียนรถ หมายเหตุ สถานที่หลายจุดตามลำดับ | กดนำทางไป Google Maps ทีละจุด หรือทั้งเส้นทาง |
| เพิ่มสถานที่โดย ค้นหา (Google) / วางลิงก์ Google Maps / เลือกที่เคยใช้ | ถึงแล้ว → ถ่ายรูปเช็คอินได้สูงสุด 5 รูป ต้องอยู่ในรัศมีที่กำหนด (เริ่มต้น 100 ม.) |
| ภาพรวมวันนี้ + แผนที่เส้นทาง + รูปเช็คอินล่าสุด + จุดที่เลยเวลานัด | บันทึกตำแหน่งตอนถ่ายรูป + หมายเหตุ |
| รายละเอียด Job: เวลาเช็คอินเทียบเวลานัด รูป ระยะห่างจากจุด | ปิดงานอัตโนมัติเมื่อเช็คอินครบ |
| คัดลอก Job ไว้ใช้กับเส้นทางประจำ | ติดตั้งเป็นแอปบนหน้าจอหลักได้ (PWA) |

## ไฟล์ในระบบ

| ไฟล์ | ใช้ทำอะไร |
| --- | --- |
| `index.html` | หน้าแอปทั้งหมด (ไฟล์เดียว) — GitHub Pages เปิดไฟล์นี้ |
| `Code.gs` | ระบบหลังบ้าน — คัดลอกไปวางใน Apps Script ของ Google Sheet |
| `SETUP.md` | คู่มือติดตั้ง (ภาษาไทย) |

ต้นฉบับแยกไฟล์สำหรับนักพัฒนาอยู่ใน `src/` และรวมเป็น `index.html` ด้วย `node dev/build.mjs`

## สำหรับนักพัฒนา

```bash
node dev/build.mjs            # รวม src/ เป็น index.html
node dev/test-backend.mjs     # ทดสอบ Code.gs ด้วยบริการ Google จำลอง
node dev/server.mjs           # เปิด http://localhost:8787 (หลังบ้านจำลองที่ /api)
NODE_PATH=$(npm root -g) TEST_PHOTO=รูป.jpg node dev/e2e.mjs   # ทดสอบหน้าจอทั้งระบบ (ต้องมี Playwright)
```

แผนที่ใช้ภาพจาก OpenStreetMap (ฟรี สำหรับการใช้งานปริมาณน้อย) เปลี่ยนแหล่งภาพแผนที่ได้ที่ `TILE_URL` ใน `config.js`
